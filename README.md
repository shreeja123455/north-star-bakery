# North Star Bakery — Touchstone 4

Responsive multi-page website for Introduction to Web Development Touchstone 4.

## JavaScript features
- Product favorites tracker on `products.html`
- Favorites saved with `localStorage`
- Contact name/email remembered with `localStorage`
- JavaScript form validation with field-specific feedback
- Functions, arrays, and objects used to organize code

Files include HTML, CSS, JavaScript, and the media folder from previous Touchstones.
